# AI Coder IDE (Android, Kotlin + Jetpack Compose)

Мобильное приложение — мини-IDE с ИИ-чатом, которое умеет читать, создавать,
изменять и удалять файлы в выбранной пользователем директории.

## Возможности
- **Верхняя панель**: выбор провайдера/модели ИИ, переключатель режима **Plan / Build / Search**.
- **Чат снизу**: поле ввода, кнопка прикрепления файла (📎) и кнопка вкл/выкл доступа в интернет — всё на векторных (SVG) иконках.
- **Меню слева** (свайп или иконка ☰): открыть директорию проекта (через системный диалог, Storage Access Framework), просмотр дерева файлов, открытие/редактирование/удаление/создание файлов.
- **Настройки** (⚙️): добавление и удаление провайдеров ИИ — есть готовые пресеты **OpenAI**, **Groq**, **OpenRouter**, либо свой OpenAI-совместимый сервер (указываете Base URL, API-ключ и список моделей).
- **Режим Build**: ИИ может сам создавать/изменять/удалять файлы в открытой папке — модель отвечает специальными блоками ` ```fileop ` с JSON-командой, приложение их выполняет и показывает результат прямо в чате (галочка/крестик у каждого файла).
- Ключи API хранятся только локально на устройстве (SharedPreferences), никуда не отправляются, кроме выбранного провайдера.

## Структура проекта
```
app/src/main/java/com/aicoder/ide/
  MainActivity.kt              — точка входа, SAF-пикеры директории/файла
  data/
    Models.kt                  — Provider, ChatMessage, AiMode, пресеты провайдеров
    ProviderStore.kt           — сохранение провайдеров/выбранной модели
    ProjectFiles.kt            — работа с открытой директорией (SAF/DocumentFile)
    AiRepository.kt            — вызов OpenAI-совместимого /chat/completions
    FileOpParser.kt            — разбор ```fileop блоков из ответа ИИ и их выполнение
  ui/
    MainViewModel.kt           — состояние экрана, вся бизнес-логика
    MainScreen.kt               — верхняя панель, чат, нижняя панель ввода
    DirectoryDrawer.kt          — боковое меню с деревом файлов

```

## Как собрать APK
1. Установите **Android Studio** (Koala/2024.1 или новее).
2. Откройте эту папку как проект (**Open** → выбрать `AiCoderIDE`).
3. Дождитесь Gradle Sync (Studio сам подтянет `gradle-wrapper.jar`, если его нет — согласитесь на предложение "Generate Gradle Wrapper" или выполните `File → Sync Project with Gradle Files`).
4. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk` — переносите на телефон и устанавливайте (разрешите установку из неизвестных источников).

Минимальный SDK — Android 8.0 (API 26).

## Настройка провайдера (пример)
- **OpenAI**: Base URL `https://api.openai.com/v1`, модели `gpt-4o, gpt-4o-mini`.
- **Groq**: Base URL `https://api.groq.com/openai/v1`, модели `llama-3.3-70b-versatile`.
- **OpenRouter**: Base URL `https://openrouter.ai/api/v1`, модели `anthropic/claude-3.5-sonnet, openai/gpt-4o`.

## Как ИИ редактирует файлы
В режиме **Build** система инструктирует модель отвечать такими блоками:
```fileop
{"action":"write","path":"src/main.py","content":"print('hello')"}
```
Поддерживаются `create`, `write`, `delete`. Приложение вырезает эти блоки из
текста, выполняет операции над открытой директорией и показывает построчный
отчёт (файл → статус) под сообщением ИИ.

## Что можно доработать
- Потоковый вывод ответа (SSE/stream=true).
- Полноценный поиск в интернете при включённом тумблере (сейчас это просто
  флаг в системном промпте — для реального поиска нужен отдельный API, например Tavily/Serper).
- Подсветка синтаксиса в редакторе файла.
